## 这是什么

面向中兴 TopFlow（MU5252）和 UFI-TOOLS-ZWRT 的原生屏幕插件。设备端以 C/C++、litehtml 和 FreeType 绘制 320×480 界面，通过已有 UFI、原厂及本机数据服务接口读写设备功能；UFI 插件管理页负责安装、切换原厂/插件屏幕、更新组件、自启动和卸载。

它是针对已分析固件和运行环境的适配实现，不是所有 TopFlow 固件通用的替换程序，也不保证与原厂全部功能等效。原厂程序、设备字体和固件库不在本仓库分发。

## 最终版包含什么

| 位置 | 已实现的界面与接口范围 |
| --- | --- |
| 首页 | 三张卡的状态、运营商、实际制式、实时上下行、QCI；普通与聚合显示跟随实际设备状态。 |
| 卡片详情 | 每卡签约上行/下行、内置卡与插拔卡切换、模块启用及相应确认/回读；未插卡不再隐藏卡源选择。 |
| 网络信息 | 信号和驻留信息、载波聚合 CA、聚合网络套餐/流量及网口状态；CA 与多链路聚合分别处理。 |
| 设备控制 | 已核实的主卡连接、APN、制式、频段和小区锁定接口；主/访客 Wi-Fi、WPS及连接设备管理；已有遨游世界引擎模式和 Selector。 |
| 短信与系统 | UFI 短信发送和转发配置、散热常开、供电和休眠、固定/自适应亮度、充电状态。 |
| 交互与锁屏 | 三个主页面、左右滑动、固定顶栏、子页返回、日夜主题；锁屏双曲线和速率过渡；无密码时显示“长按解锁”，设置密码时走原厂验证。 |
| UFI 管理页 | 原厂/插件屏幕切换、受信版本组件更新、自启动开关、恢复原厂后清理本插件组件。 |

数据缺失、过期、卡片未启用或未插卡时显示明确状态或未知值，不借用其他卡的数据。5G-A 只在接口明确报告时显示，不以载波聚合、多卡聚合或测速结果推断。

## 获取和使用

最终原始插件文件放在 [`releases/`](releases/)：[`topflow-screen-0.2.1.txt`](releases/topflow-screen-0.2.1.txt)。通过 UFI 已有插件导入功能上传 TXT，再在插件管理页操作。它不是商店内部包装文件，不应手工添加 `KANO_META`。

已有旧版时，替换原 TopFlow TXT 记录并刷新 UFI，再点击管理页中的“更新到 v0.2.1”；不要叠加多份同名功能记录。更新过程会先恢复原厂再更新组件。原先开启开机自启动的，组件更新后需重新开启。

**已经安装早期私发 v0.2.1 的用户：** 公开整理版补全了许可证和构建清单，组件哈希与私发同版本不同。请先用旧管理页恢复原厂并完整卸载组件，再导入这里的公开版；不要绕过哈希或归属检查。以上一键更新仅适用于管理页已识别并允许迁移的旧版本。

屏幕选择和恢复原厂仅在 UFI 插件管理页操作。开机自启动默认关闭；开启后使用 UFI 官方插件启动入口。卸载只清理已确认属于本插件的内容，遇到未知归属、文件变更或原厂恢复失败时停止，不以删除未知文件来冒充完整卸载。

## 源码与本地构建

`src/` 是 UFI 管理页及网页界面，`native/` 是设备端程序、UI 与测试，`tools/` 是构建工具。公开源码包排除了设备抓取、原厂资源、私有凭据、编译器缓存与未审阅参考包。

使用固定版本依赖构建，并按 [docs/BUILD.md](docs/BUILD.md) 完成准备、测试及打包。UFI SDK 从官方来源获取并校验固定哈希；未将它标注为本项目非商用许可或 MIT。设备字体、共享库和本地构建输入的边界也见构建文档。

## 验证范围和已知限制

用户已明确确认完成实机验收，并提供了本页的实机测试照片。该验收结论来自用户的实际使用反馈。本次源码公开整理、脱敏、重新编译和打包在电脑上完成，没有再次连接或修改设备。

[公开构建记录](docs/PUBLIC-BUILD-VERIFICATION.json) 区分用户实机验收与电脑检查：其中构建器的 `hardwareVerified=false` 表示本次电脑构建没有自动执行新的实机验收，不表示用户未测试。公开整理版因许可证和构建清单补全而与早期私发同版本具有不同文件哈希。

原交付记录包含 38 组原生测试、85 项界面/数据测试、21 项打包/导入测试、32 项插件中心检查；锁屏覆盖 20 个布局、4464 个命中点和 8 个实际动画帧。源码/载荷哈希及敏感信息扫描另有检查。上述是对应交付版本的本地结果，不能证明真实帧率、短信投递、切卡后注册、开机接管、休眠唤醒或卸载的实机效果；公开整理后的检查按随仓库的构建说明复现。

以下原厂项目仍未完整移植：全部外卡独立拨号/频段/套餐、完整流量提醒、RJ45/WAN/UPnP/DMZ 配置、充值认证二维码、固件升级、多语言、NFC、充电宝/小电流、全部通知和证书、完整短信历史分页/批删、SIM PIN 修改/启停/保存、网络锁解锁。小区采集不启用；纯 IPv6 聚合 TCP 的补充观测未实现。无相应证据时显示未知，不声称功能已完成。

屏幕切换必然涉及显示进程与显示资源交接，设备控制会通过已有接口执行对应设置。本项目不承诺“绝对不影响系统”，也不提供后续修复或技术支持。

## 插件中心与数据说明

管理页包含插件中心版本检查和官方 SDK 接入。只有本 TXT 版本与中心已发布版本一致时，才按实现条件在可见 UFI 页面发送宿主持久匿名 UUID、设备型号/固件、插件版本和 Wi-Fi 终端数量；隐藏页面暂停。它不发送密码、短信、SSID 或终端明细，没有新增原生常驻统计进程。连接失败不阻断屏幕控制。

本 GitHub 源码公开不等于已向插件中心发布。自行修改或派生时，应审阅 [官方开发文档](https://plugin.shaneyun.com/developers)，使用自己合法管理的插件身份，不能冒用原项目发布身份。
