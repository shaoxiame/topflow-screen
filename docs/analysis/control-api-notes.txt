6. 实际功能边界
接口与负载经过精确版本静态核对，本轮未做设备写入验证。
TopFlow 0.10.79 仅 5G 主卡可发短信。外挂 4G1 / 4G2 的短信发送被 datad 明确拒绝，UI 必须禁用。
锁 LTE/NR 小区作用于 5G 主基带的 LTE/NR 制式；不可当作给 4G1/4G2 分别锁站。
用户明确禁止小区采集，本模块没有实现 neighbor/scan/采集开启动作，也不读取对应端点。
频段“自动”必须写全设备支持频段。本地 UFI main.js 3676–3680、3759–3768 的注释记录
HAR 实测空串会清空允许列表导致断网；因此优先遵从本设备面板实证，不照抄 datad 文档的空串自动说明。
QCI/AMBR 是运营商下发状态；本模块只显示，不提供伪造“修改 QCI 等级”功能。
Wi-Fi 修改会引发无线网络重载。聚合开关会切换网络模式及 mwan3/ICG 进程状态。
[REDACTED_SENSITIVE_CONTEXT]
短信发送和测试可能收费；UI 确认应展示确切号码/目的地，不能只问“保存吗”。
本模块不接管 DRM，不装触摸驱动，不操作原厂 devui，不实现遨游世界核心服务。
原厂切回入口的实际执行由后续单独验证的原生生命周期适配承担。
