# v0.2.7 · UFI Shell 状态读取修复

**By：善恶** · [GitHub：shaoxiame](https://github.com/shaoxiame)。特别鸣谢 **UFI-TOOLS-ZWRT** 面板及开发者。

下载原始 [`topflow-screen-0.2.7.txt`](topflow-screen-0.2.7.txt)。文件包含版本头与完整脚本包装，不含商店内部 `KANO_META` 标记、旧商店入口或演示数据。配套 [元信息文件](topflow-screen-0.2.7.txt.meta.json) 供官方源维护者使用，手动导入只需 TXT。使用本目录的 [SHA256SUMS](SHA256SUMS) 校验成品。

## 本次修复

v0.2.6 的状态命令过长，UFI 会返回“返回值或执行结果未确认”。本版提取重复校验逻辑，保留精确文件哈希、归属检查和锁内核验，并在发送前检查命令长度。修复后的完整状态命令已通过实际 UFI 接口只读验证，没有修改设备或执行屏幕切换。

保留快速开机假关机熄屏与输入隔离、UFI 首页透明卡片、宿主配色确认弹窗，以及此前的 Wi-Fi 状态同步、锁屏壁纸、长按电源键菜单、版本更新、自启动和完整卸载功能。新版本原生屏幕程序与 v0.2.6 字节一致；本次没有新增屏幕触摸、休眠和关机的实机验收。

## 导入与更新

1. 在 UFI“插件功能”中替换旧 TopFlow TXT 记录，提交并刷新。也可先移除旧 TXT 记录、提交刷新，再导入本版并再次提交刷新。保留其他插件，不要叠加多份 TopFlow 记录。
2. 确认首页卡片显示 **v0.2.7**，等待读取状态。无组件时按提示安装；已有受信旧组件时点击“更新到 v0.2.7”。无需先在旧卡片中完整卸载设备组件。
3. 管理器核验旧组件、恢复原厂、清理并安装新版。支持已核验的 v0.2.6、v0.2.5、v0.2.4 等历史归档；未知或被修改的组件不会强行覆盖。
4. 更新期间保持页面打开，以在浏览器内存保留并恢复已核验的锁屏壁纸。原先启用开机自启动的，更新后重新开启。

选择壁纸只产生本地预览，点击“应用壁纸”并确认后才上传固定尺寸的像素文件。替换、恢复默认和完整卸载清理已识别的插件壁纸与事务文件；未知文件不会自动删除。
