# v0.2.3 · 电源键长按菜单版

下载原始 [`topflow-screen-0.2.3.txt`](topflow-screen-0.2.3.txt)，通过 UFI-TOOLS-ZWRT 的插件导入功能上传，点击“提交”保存并刷新，再从管理页操作。文件含版本头和完整 `<script>` 包装，不含商店内部 `KANO_META` 标记、旧商店入口、遥测 SDK 或演示数据。

使用本目录的 [SHA256SUMS](SHA256SUMS) 校验下载文件；以对应文件名的最终哈希为准。

v0.2.2，以及公开版与早期私发 v0.2.1，按已登记的精确归档哈希识别。替换原 TopFlow TXT 记录、提交并刷新后，管理页识别出受信组件时可直接点击“更新到 v0.2.3”；无需先手动卸载。管理器仍会在内部完成原厂恢复、旧组件核验和更新，未知或被修改的组件不会强行覆盖。

**新增电源键菜单：** 按住实体电源键约 1.2 秒打开菜单。亮屏直接显示，不先唤醒或重新锁定；熄屏先沿用原有唤醒流程。PIN 或防误触锁定时只能查看菜单，关机和重启禁用，取消后仍保留原锁；解锁后选择关机或重启，再单独确认才发送请求。

打开菜单会撤销未确认的业务操作，取消回到原页面及滚动位置；休眠或显示重新同步会清除菜单和旧选择。电源请求使用已有本机接口，提交前重新检查能力，每次确认只发一次；超时或断线不自动重试，也不把请求接受当成关机/重启已完成。

管理页保留日夜主题、固定头尾、内容独立滚动、状态卡、开机启动开关和卸载入口。原厂恢复、插件屏幕切换及生命周期脚本的既有保护保持不变。

配套 [`topflow-screen-0.2.3.txt.meta.json`](topflow-screen-0.2.3.txt.meta.json) 按 [UFI 官方文档](https://tapan.top/UFITOOLS-U60Pro/1.0.0%E6%96%B0%E7%89%88%E6%9C%AC%E6%96%87%E6%A1%A3) 提供商店元数据；手动安装只需导入 TXT。官方商店使用 UFI 内置源，本项目不提供替代商店源，也不声称已经由官方商店收录。

其他旧版只在管理页识别为允许迁移时使用更新按钮；更新后需重新开启此前使用的自启动。屏幕切换与恢复原厂均在插件管理页完成。

用户已确认 v0.2.1 完成实机验收，并提供真实设备测试照片。v0.2.3 仅在电脑开发和验证，未连接或修改设备；旧版验收不自动覆盖新增电源菜单、真实电源键及关机/重启效果。最终验证结果见 [公开构建记录](../docs/PUBLIC-BUILD-VERIFICATION.json)，适用范围与已知限制见 [项目主页](../README.md)。
