# v0.2.6：快速开机假关机联动与 UFI 透明卡片

本次修改在电脑开发和验证，不连接设备、不安装插件、不修改原厂或 UFI 配置。是否完成本机测试以 `../PUBLIC-BUILD-VERIFICATION.json` 的当前版本记录为准；不把旧版用户实机验收扩展为本次新行为的验收。

## 快速开机

用户反馈：开启快速开机后，关机状态下插件画面仍然亮着，触摸仍有响应，但网络功能不能使用。

现有源码证据将设置与状态分开：`quicken_power_on` 是快速开机选项；原厂临时配置 `/etc/config/zwrt_zte_mc_tmp` 的 `mode.mode_main_state` 才表示实际电源状态。数据服务的 `docs/STATE_SCHEMA.md` 与 `rust/src/cooling.rs` 已处理 `mode_power_off*`，其中包括快速开机假关机状态；此时用户态进程可以继续运行。单凭服务断线、Wi-Fi 关闭或快速开机选项开启，不能推断设备已关机。

旧屏幕程序没有将这组电源状态接入显示/输入控制。原有短按唤醒、后台状态读取和亮度更新仍可能运行，形成“画面可点、功能无效”的状态。

本版读取原厂已有状态，复用原有 LCD 关闭与锁屏流程。假关机期间撤销未确认操作、抑制本地唤醒并丢弃输入，保留监管心跳；没有新建常驻进程，不写原厂电源状态，不用本地触摸替代原厂开机。状态未知或文件暂时不可用不会解除已观察到的假关机限制；明确恢复开机后重新经过既有显示和锁屏策略。

针对性测试覆盖状态解析、快速开机选项与实际关机的区分、假关机后的输入和亮度阻断、等待接口期间取消操作、残留输入处理、未知状态及恢复流程。测试使用电脑状态文件、时间、显示和接口替身；实际电源按键、固件状态转换和休眠仍需设备验证。

## UFI 首页透明度

用户提供的参考插件以宿主卡片背景和模糊参数呈现玻璃效果。旧 TopFlow 首页使用宿主页面底色并叠加实体内卡片，挡住了 UFI 壁纸。

本版仅在 TopFlow 的 CSS 作用域内调整：外壳使用 `--dark-card-bg` 和 `--blur-rate`，内层卡片透明，文字和按钮继承 UFI 配色；只在外壳使用一层模糊。没有通过整体 opacity 降低文字清晰度，没有新增设备请求、轮询或日志。

确认弹窗单独采用 `--dark-bgi-color`，缺失时回退到宿主页面底色。弹窗挂在 body 时，管理器同时复制该颜色变量，保留局部容器主题。色彩混合具有 CSS 支持检测和旧浏览器回退。

本地预览支持 `?wallpaper` 合成壁纸和 `?mobile` 窄列模式。预览是开发工具，不进入成品 TXT，不连接设备。
