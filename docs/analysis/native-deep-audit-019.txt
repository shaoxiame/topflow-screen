本轮修复
1. 连接设备限制：原判断允许任意非 allow 字符串，被遗漏/损坏的过滤模式可能显示操作入口。现在仅接受官方 deny/disable；白名单和未知状态不可修改。限制只允许当前在线的 Wi-Fi 设备，解除只允许 deny 模式中确实列在黑名单的目标。确认时再次复查，已变化/有线/未知/已移除目标停止提交。回读必须明确 deny 模式，不能用未知或白名单模式下的空 blocked 数组冒充解除成功。官方 client.block 在 disable 模式开启黑名单的行为保留，并在确认页说明。
2. 访客设置：此前只使用打开页面时的缓存。现在点击确认后调用既有 wifi.guest.status 只读动作，核实目标频段 supported、当前开关/时限/管理访问状态仍与所见一致，且数值有效；变化、未知、读取失败、锁屏/取消均在提交前停止。只发送一次 wifi.guest.set，成功仍要求后端 verified 和独立回读匹配。没有自动重试。访客 section 重复也不再取第一个。
3. 访客详情：补上官方现有 clients、left_seconds 与 active_time_minutes，显示连接人数和有效期剩余；已启用且明确 0 分钟显示不限时，关闭/未知显示 —。只在既有进入/刷新请求中读取，不增加定时查询。
