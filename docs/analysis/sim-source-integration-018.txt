Control and resource behavior
[REDACTED_ENCODED_OR_IDENTIFIER]
Only opening card details, explicit refresh, confirmation and post-submit
verification read factory source. There is no periodic source collection or
additional daemon/file/log. Reads cache for3seconds unless explicitly refreshed.
The existing bounded vendor_exec uses direct argv (no shell), ubus -t1, a bounded
output buffer and process timeout. Raw response buffers are cleared after parsing;
only source integers remain in memory.
Disabled/unknown secondary modules cannot switch and are not implicitly enabled.
Known raw source is independent of whether a card is physically present: switching
away from an empty removable card is allowed when the module is enabled.
Confirmation rechecks selected card, source, enabled state and unlocked control
permission. After the last busy frame it rechecks cancellation/permission; the
setter also rejects cancellation at entry. A second tap cannot resubmit.
Transport errors can happen after a request was applied, so the code still reads
back without retrying writes. Only a matching raw source is reported successful;
no network-registration claim is made. Readback expires after15seconds.
