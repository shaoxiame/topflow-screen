# v0.2.4 · UFI 首页卡片与锁屏壁纸

**By：善恶** · [GitHub：shaoxiame](https://github.com/shaoxiame)

下载原始 [`topflow-screen-0.2.4.txt`](topflow-screen-0.2.4.txt)，通过 UFI-TOOLS-ZWRT 的插件导入功能上传，点击“提交”保存并刷新。TopFlow 管理卡片直接显示在 UFI 首页“功能列表”下方，不再使用独立管理弹窗。文件含版本头和完整 `<script>` 包装，不含商店内部 `KANO_META` 标记、旧商店入口、遥测 SDK 或演示数据。

使用本目录的 [SHA256SUMS](SHA256SUMS) 校验最终下载文件。配套 [`topflow-screen-0.2.4.txt.meta.json`](topflow-screen-0.2.4.txt.meta.json) 是官方源元数据；手动安装只需 TXT，不要把 JSON 当作插件导入。

## 本版变化

- 管理卡片跟随 UFI 的深浅主题和背景；清理宿主继承的文字阴影和滤镜，压缩大块留白，在电脑与手机上自适应排布。
- 卡片保留一键切换、状态刷新、组件更新、自启动和卸载；不另设替代商店入口。
- 上传 JPG、PNG 或静态 WebP 作为锁屏壁纸；电脑/手机浏览器裁切预览后，仅上传约 300 KiB 的固定 RGB565 像素数据。
- 锁屏重排速率与图表，保留普通/聚合模式、运营商、制式及“长按解锁”动效；自定义背景下叠加遮罩保证可读。
- 元信息及插件卡片署名为“By：善恶”；已有版权声明和第三方许可证保持原授权。

## 已安装旧版

v0.2.3、v0.2.2，以及公开版和早期私发 v0.2.1，按已登记的精确归档哈希识别。替换原 TopFlow TXT 记录、点击“提交”并刷新后，点击“更新到 v0.2.4”。本版包含新的原生壁纸加载器，需要更新设备组件；仅替换 TXT 不能让旧渲染器读取壁纸。管理器内部完成原厂恢复、旧组件核验、更新与启用，无需先手动卸载。

不要叠加同名功能记录，也不要删除其他插件。未知或被修改的组件不会强行覆盖。原先开启开机自启动的，组件更新后需重新开启。长按电源键关机/重启菜单继续保留；选择后需单独确认，锁定时先解锁。

## 壁纸与卸载

选择图片只产生本地预览，点击“应用壁纸”并确认后才上传。图片最大 12 MB；浏览器居中裁切为 320×480，原图与元数据不会上传。文件通过长度、头部和 SHA-256 校验后原子替换，下一次锁屏或唤醒生效。设备不新增图片解码器、后台轮询或持续日志。

“恢复默认”只删除已识别的插件壁纸。壁纸使用 UFI 命令接口受锁分块，每块最多 24 KiB，每块验证随机事务编号、开机 UUID、哈希及偏移。响应未知时保留原图，不自动重传或提交，可明确清理后重新选择图片。完整卸载清理壁纸和已识别事务；迟到的旧分块不能重建文件或目录，同图新事务也不会误接收旧分块。原生组件归档仍沿用既有上传完成核验，未知或不安全文件不会被自动删除。
