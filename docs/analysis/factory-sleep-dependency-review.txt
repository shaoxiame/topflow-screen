Concrete cross-process dependency

1. [REDACTED_ENCODED_OR_IDENTIFIER].txt records [REDACTED_ENCODED_OR_IDENTIFIER] as an
   independent running process. Its init script uses procd respawn, START=47;

2. In zte_topsw_sleep_faw, the event-registration path references
   zwrt_deviceui_event.lcdstatus at virtual address 0x529c. A relocation at
   0x2faf0 resolves the stored callback to 0xcc44.
3. Callback 0xcc44 identifies itself as [REDACTED_ENCODED_OR_IDENTIFIER] in its diagnostic
   string and parses a string field named lcd_status (0xcd20). Parse failures or
   missing fields log an error and return without running either state transition.
4. The on comparison uses literal "on" at 0x14072, then dispatches an internal
   state message and calls the function through GOT 0x2fd18 (RELA addend 0xbc34).
   The off comparison uses literal "off" at 0x14deb, dispatches the opposite state
   and calls GOT 0x2fc68 (RELA addend 0xbe08).
5. The shared argument at 0x31168 is initialized from "zteSleepBacklight" at
   0x5864. Function 0xbc34 builds an echo command ending in
   /sys/power/wake_lock (0xbcc4); function 0xbe08 uses
   /sys/power/wake_unlock (0xbe98). Both have bounded error retries.
   This proves that the LCD event influences a kernel wake lock, not merely a
   cosmetic screen-state label.

Practical consequence / uncertainty

The current native replacement has no zwrt_deviceui_event.lcdstatus emission or
corresponding factory wake-lock lifecycle. A last on event can therefore leave the
sleep manager's backlight lock unchanged after factory exit; a last off event can
leave it unaware that the replacement display became active. This can alter
suspend eligibility or wake behavior. Those are inferences from the demonstrated
[REDACTED_SENSITIVE_CONTEXT]
paths have not been proven to compensate. A custom framebuffer heartbeat neither
updates this kernel lock nor proves that system sleep still behaves correctly.

Do not patch this by guessing and blindly sending a single off/on event. A correct
replacement needs the full sleep/wake protocol, state restoration and transitions,

An absolute trial lease would only limit exposure; it would not prove equivalence.
