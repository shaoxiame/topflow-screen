Implementation and validation boundaries
The new path validates persistent policy and ownership, opens DRM and submits
an initialized black buffer, then checks sensor readiness. Automatic mode may
use the source-verified init/enable sequence once, only for observed state zero
under the active owned guard. It still requires genuine enable/lux readback.
Sensor I/O errors, invalid values and init/enable errors have separate bounded
codes. There is no fabricated sensor value or unconditional driver reset.
